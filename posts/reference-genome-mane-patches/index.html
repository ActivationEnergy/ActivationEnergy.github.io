2026年10月2日
3 分钟
1084 字

NCBI 的 MANE v1.5 官方 summary 中，有 64 个基因的 MANE Select 注释在 genomic patch 上，下表完整列出这 64 条 MANE Select patch 转录本。每行的官方 RefSeq patch 和 mRNA 位置来自 NCBI MANE v1.5 summary ；primary／FIX／ALT 三栏列出该 NM 在本地 UCSC 转录本数据库中可见的所有 scaffold 与其 exon 覆盖的基因组跨度，总共 162 个定位。坐标统一写成 1-based、两端包含，括号内是链方向；由 UCSC 0-based 半开 exon 记录换算。粗体标出与 MANE 官方所选 patch 对应的 UCSC 定位，— 表示该类别没有记录。所有 64 个官方所选 patch 的区间及方向都与 MANE RefSeq GFF3 的 mRNA 记录 相符，NCBI／UCSC 名称由 GRCh38.p14 assembly report 核对。

读表注意：这是一个 NM 的全部可见比对定位，不表示每个位置都有完整的 exon／CDS，也不表示设计或常规 reads 比对时应把它们全部采用。表中的区间是基因组跨度，包含内含子；要提取单个 exon／CDS，应以对应注释为准。NCBI GFF3 文档：“Column Specifications”节
