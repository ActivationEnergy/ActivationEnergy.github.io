codu 0.2.0：补上 Windows 和 Linux 的安装方codu 0.2.0：补上 Windows 和 Linux 的安装方式

前段时间，我写过一篇文章，介绍自己做的 Codex 会话管理工具 codu

codu 可以在终端中浏览本地 Codex 会话，查看时间、名称、工作目录、状态和文件大小，也可以搜索、排序、继续、归档、恢复或删除会话。

第一版主要围绕 macOS 开发，安装方式也是 Homebrew。最近我把它整理成了标准 Python 软件包，并发布了 codu 0.2.0，为 Windows 和 Linux 补上了安装入口。

先说重要提醒

Windows 和 Linux 版本目前都没有做过实际使用测试。

虽然项目已经加入 Windows、Linux 和 macOS 的自动化测试，能够检查软件包安装、命令启动和核心逻辑，但这不等于在真实终端中完整使用过。

尤其是全屏界面、方向键、中文宽字符显示，以及进入、归档和删除真实 Codex 会话等操作，目前只在 macOS 上实际使用过。

因此，Windows 和 Linux 支持现阶段仍然属于实验性质。如果准备尝试，建议先使用浏览和归档功能，不要急着删除重要会话。

macOS 怎样更新？

macOS 仍然推荐使用 Homebrew。

如果已经安装过旧版本，可以运行：

PLAINTEXT 
brew update  
brew update  

检查版本：

PLAINTEXT 
codu --version
codu --version

应该会看到：

PLAINTEXT 
codu 0.2.0
codu 0.2.0

如果是第一次安装：

PLAINTEXT 
brew tap ActivationEnergy/cask  
brew tap ActivationEnergy/cask  

Windows 和 Linux 怎样安装？

Windows 和 Linux 推荐使用 uv 安装固定版本的 wheel：

PLAINTEXT 
uv tool install https://github.com/ActivationEnergy/codu/releases/download/v0.2.0/codu-0.2.0-py3-none-any.whl
uv tool install https://github.com/ActivationEnergy/codu/releases/download/v0.2.0/codu-0.2.0-py3-none-any.whl

也可以使用 pip：

PLAINTEXT 
python -m pip install https://github.com/ActivationEnergy/codu/releases/download/v0.2.0/codu-0.2.0-py3-none-any.whl
python -m pip install https://github.com/ActivationEnergy/codu/releases/download/v0.2.0/codu-0.2.0-py3-none-any.whl

或者使用 pipx：

PLAINTEXT 
pipx install
pipx install

以上三种方法选择一种即可，不需要全部执行。

在 Windows PowerShell 中，如果没有 python 命令，可以把它换成 py：

PLAINTEXT 
py -m pip install https://github.com/ActivationEnergy/codu/releases/download/v0.2.0/codu-0.2.0-py3-none-any.whl
py -m pip install https://github.com/ActivationEnergy/codu/releases/download/v0.2.0/codu-0.2.0-py3-none-any.whl

Windows 建议使用 Windows Terminal 和 PowerShell，目前以 x64 Python 为支持基线。

安装软件包时，会自动安装 Windows 全屏终端界面需要的 windows-curses。

Linux 通常已经包含 Python 的 curses 支持；部分精简发行版可能需要另外安装对应的系统包。

使用前仍然需要：

  • Python 3.11 或更新版本
  • 已安装并配置好 Codex CLI
  • codex 命令能够在终端中正常运行

安装后怎样使用？

三个平台上的使用方式相同。

浏览全部会话：

PLAINTEXT 
codu
codu

只看当前项目：

PLAINTEXT 
codu .
codu .

输出普通文本：

PLAINTEXT 
codu --plain
codu --plain

输出 JSON：

PLAINTEXT 
codu --json
codu --json

第一次打开全屏界面时，可以按 ? 查看帮助。

常用操作仍然包括：

  • 使用方向键或 j、k 移动
  • 使用 / 搜索
  • 使用空格标记会话
  • 按 r 进入当前会话
  • 按 a 归档或恢复会话
  • 按 d 删除会话

删除是永久操作。如果此前用空格标记了多个会话，删除会作用于所有已标记项。

拿不准的会话建议先归档，不要直接删除。

这次更新还做了什么？

除了增加 Windows 和 Linux 的安装方式，这次还做了几项基础工作：

  • 将 codu 整理成标准 Python 软件包
  • 支持 uv、pip 和 pipx 安装
  • Windows 自动安装 curses 依赖
  • 增加 codu –version
  • 调整会话恢复时的工作目录处理
  • 增加 Windows 路径和命令启动测试
  • 增加 Windows、Linux、macOS 的自动化测试
  • 每个正式版本自动生成 wheel 和源码包

这些改动主要是在补齐跨平台安装和发布基础，codu 原来的功能和操作方式没有明显变化。

为什么暂时不直接说“全面支持”？

跨平台工具真正麻烦的地方，往往不是能不能启动，而是不同终端、不同 Python 安装方式和不同 Codex CLI 版本之间的细节。

Windows Terminal、PowerShell、Linux 发行版、字符宽度、键盘输入和子进程恢复，都可能表现得不完全一样。

所以这次更准确的说法是：

Windows 和 Linux 已经可以安装，代码和自动化测试也已经准备好，但还需要真实用户环境的验证。

如果你正好使用 Windows 或 Linux，欢迎试用并反馈。

报告问题时，最好附上：

  • 操作系统和版本
  • Python 版本
  • Codex CLI 版本
  • 使用的终端
  • 安装方式
  • 错误信息或脱敏截图

请不要提交真实会话内容、访问令牌、项目凭据或其他私人信息。
